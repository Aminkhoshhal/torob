# ربات محلی ترب

Python 3.12+، Playwright Chromium قابل‌مشاهده، SQLite، تلگرام با Long Polling. تمام پردازش روی مک است؛ سرور و Webhook لازم نیست. فایل خروجی از طریق تلگرام ارسال می‌شود.

## وضعیت واقعی دسترسی و تست

بررسی در **۲۰۲۶-۱۱-۱۲** انجام شد:

- صفحهٔ جستجوی «تشک» و صفحهٔ محصول واقعی پاسخ ۲۰۰ دادند. دادهٔ `__NEXT_DATA__`، ۲۶ نتیجهٔ اولیه و لینک‌های DOM بررسی شدند.
- صفحهٔ بعدِ واقعی API پاسخ ۲۰۰ داشت (`results`, `next`). دو گروه فروشندگان محصول کامفورت نیز پاسخ ۲۰۰ داشتند؛ شمار اعلامی ۴۰ پیشنهاد اینترنتی و ۲۳ پیشنهاد حضوری بود، نه لزوماً همین تعداد فروشگاه یکتا.
- یک درخواست بررسی با ۵۰۴ مواجه شد.
- **تست نهایی `تشک / 10` با کد پروژه اجرا شد و با HTTP 490 متوقف شد: صفر محصول از ۱۰. این تست موفق نیست.** بعد از آن هیچ درخواست دیگری به ترب ارسال نشد. کد نهایی ۴۹۰ را هم محدودیت دسترسی محسوب می‌کند؛ این تغییر با تست محلی بررسی شده، نه درخواست زندهٔ مجدد.
- تست نهایی روی Linux و Headless بود (`RESOLVE_BUY_LINKS=false`). اجرای Headed در محیط آزمایش با `Missing X server / DISPLAY` شکست خورد. تست روی macOS، دریافت ۱۰ محصول کامل، حل لینک خرید در سایت واقعی و ارسال واقعی تلگرام **تأیید نشده‌اند**؛ توکن تلگرام در اختیار نبود.
- `test_core.py` آزمون‌های محلی با fixture/mock است؛ موفقیت آن به معنی موفقیت اسکرپینگ زنده نیست.

`https://torob.com/robots.txt` در زمان بررسی شامل `User-agent: *` و `Disallow: /search/` بود. این فایل مجوز استفاده نیست و جستجوی خودکار را منع می‌کند. جستجوی برنامه پیش‌فرض خاموش است؛ فقط پس از بررسی شرایط و احراز مجازبودن استفاده، `SEARCH_PERMISSION_CONFIRMED=true` قرار دهید. این تنظیم محدودیت سایت را دور نمی‌زند و مجوزی ایجاد نمی‌کند. شرایط قراردادی کامل سایت در این بررسی تأیید نشده‌اند.

## نصب macOS — Apple Silicon و Intel

Python رسمی یا Homebrew و VS Code با افزونه‌های Python و Python Debugger نصب باشند. با Homebrew:

```bash
brew install python@3.12
cd /path/to/torob-bot
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m playwright install chromium
cp .env.example .env
chmod 600 .env
```

Playwright نسخهٔ مناسب معماری مک را دریافت می‌کند. نیازی به ChromeDriver، Docker، Rosetta یا `sudo pip` نیست. فولدر پروژه را در VS Code باز کنید، مفسر `.venv/bin/python` را انتخاب کنید. `F5` یا ترمینال یکپارچه:

```bash
source .venv/bin/activate
python -m torob_bot
```

## ساخت بات و User ID بدون بات واسط

۱. در بات رسمی **@BotFather**، `/newbot` بفرستید و نام و username بسازید.
۲. توکن را فقط در `.env` مقابل `TELEGRAM_BOT_TOKEN` وارد کنید؛ در چت، اسکرین‌شات یا Git قرار ندهید.
۳. برای دریافت ID، قبل از اجرای بات اصلی:

```bash
python -m torob_bot --whoami
```

به بات خودتان در چت خصوصی `/start` بفرستید. فقط ID عددی فرستنده در ترمینال محلی چاپ می‌شود؛ پاسخی برای کسی ارسال نمی‌شود. ID خودتان را تشخیص دهید، `Ctrl+C` بزنید و مثلاً `ALLOWED_USER_IDS=123456789,987654321` را در `.env` بنویسید. این‌ها مثال‌اند؛ باید با شناسه‌های واقعی جایگزین شوند. سپس بات اصلی را اجرا کنید. Username و Chat ID گروه جایگزین User ID نیستند.

اگر توکن قبلاً برای Webhook استفاده شده، Long Polling آن را حذف می‌کند؛ یک توکن را هم‌زمان در دو برنامه استفاده نکنید. پیام‌های قدیمی موقع شروع بات حذف می‌شوند تا دستور قدیمی ناخواسته اجرا نشود.

## دستورات

| دستور | کاربرد |
|---|---|
| `/start` | راهنمای کوتاه |
| `/scrape تشک 10` یا `تشک 10` | جستجو؛ آخرین واژه تعداد است، بین ۱ و ۱۰۰۰۰ |
| `/status` یا `/status 1` | وضعیت آخرین عملیات خودتان یا شمارهٔ مشخص |
| `/pause` | لغو کار جاری، بستن مرورگر و حفظ checkpoint |
| `/resume` یا `/resume 1` | ادامهٔ صف قبلی؛ موفق‌ها تکرار نمی‌شوند، ناموفق‌ها دوباره بررسی می‌شوند |
| `/stop` | توقف بدون حذف اطلاعات؛ بازیابی بعدی ممکن است |
| `/export` یا `/export 1` | خروجی کامل یا جزئی از داده‌های فعلی |

فقط کاربران مجاز، فقط چت خصوصی و فقط عملیات متعلق به خودشان کنترل/خروجی دارند. یک worker فعال در کل برنامه مجاز است. قفل فرایند از اجرای دو برنامه روی همان `DATA_DIR` جلوگیری می‌کند؛ از دو DATA_DIR برای اسکرپینگ هم‌زمان استفاده نکنید. عملیات قدیمی با شناسهٔ خودش قابل‌بازیابی است.

در پایان موفق/ناقص، Excel و ZIP شامل سه CSV خودکار ارسال می‌شوند. در توقف ناشی از محدودیت یا خطا، از `/export` برای خروجی جزئی استفاده کنید. قطع تلگرام پردازش را پاک نمی‌کند؛ پس از اتصال دوباره `/status` و `/export` بزنید. فایل‌های بزرگ‌تر از ۴۹ MiB محلی باقی می‌مانند.

## داده و ترتیب

- N، تعداد **محصول یکتا** به ترتیب اولین حضور در نتایج پیش‌فرض ترب است؛ تبلیغات نمایش‌داده‌شده حذف نمی‌شوند. دو لینک تصویر/عنوان یک کارت دو محصول نیستند.
- ابتدا صف حداکثر N محصول با رتبه ذخیره می‌شود، سپس جزئیات همان‌ها استخراج می‌شود. محصول ناموفق با نتیجهٔ N+1 جایگزین نمی‌شود. اگر سایت کمتر از N نتیجه بدهد یا محدودیت رخ دهد، وضعیت ناقص اعلام می‌شود؛ تضمین مصنوعی N رکورد موفق وجود ندارد.
- ترتیب صفحهٔ اول با لینک‌های واقعی DOM تطبیق داده می‌شود. ادامه از `nextUrl` و `next` واقعی منبع بارگذاری بیشتر وب‌سایت است؛ شمارهٔ صفحه، URL فروشندگان یا کلاس CSS حدس زده نمی‌شود. ممکن است نتایج سایت بین اجراها تغییر کنند؛ Resume صف ثبت‌شده را نگه می‌دارد.
- تنها سلکتورهای استخراج: `script#__NEXT_DATA__` و `a[href^="/p/"]`؛ در صفحهٔ واقعی مشاهده شدند. کلیدهای جزئیات: `baseProduct`, `structural_specs.headers[].specs`, `breadcrumbs` و گروه‌های `products_*`.
- برند از مشخصات یا breadcrumb دارای `brand_id` است. مدل از فیلد مشخصات خوانده می‌شود و از عنوان حدس زده نمی‌شود. فیلد ناموجود در SQLite برابر SQL NULL است؛ در Excel/CSV خانهٔ خالی.
- قیمت عددی و متن اصلی قیمت همراه واحد درج می‌شوند؛ واحد از متن واقعی خوانده می‌شود، ریال/تومان تبدیل نمی‌شود. تصویر به‌صورت URL ذخیره می‌شود، نه فایل تصویر یا عکس جاسازی‌شده در Excel.
- تمام پیشنهادهای در دسترسِ فروشندگان اینترنتی و حضوری از گروه‌های واقعی جمع‌آوری می‌شوند. چند پیشنهاد یک فروشگاه مستقل‌اند؛ تکرار تبلیغاتی همان پیشنهاد حذف می‌شود. نام، شناسه، قیمت، نوع و لینک هر پیشنهاد جدا ذخیره می‌شود.
- `sellers_complete=1` فقط پس از تکمیل گروه‌ها و کنترل شمار پاسخ ثبت می‌شود. اگر ساختار/شمار سازگار نباشد، تکمیل ادعا نمی‌شود.
- لینک واسط ترب در `torob_url`، مقصد مستقیم در `direct_url` و مبدأ سایت فروشنده در `website` است. با `RESOLVE_BUY_LINKS=true` ریدایرکت‌های واقعی ترب دنبال می‌شوند، ولی درخواست به فروشگاه ارسال نمی‌شود. مقصد نیازمند توکن/امضا یا مقصد ناموجود NULL می‌ماند. فروشگاه حضوری الزاماً وب‌سایت ندارد.
- شناسه‌های نشست از لینک خروجی پاک می‌شوند؛ لینک پاک‌شدهٔ واسط ممکن است به نشست جدید نیاز داشته باشد. فرمول‌های احتمالی سایت در Excel/CSV خنثی می‌شوند.

## خطا، توقف و بررسی دستی

`REQUEST_DELAY=5` حداقل فاصلهٔ ثانیه‌ای برای عملیات scraper است (حداقل قابل‌تنظیم ۳). این فاصله برای بارگیری عادی تصاویر و CSS نیست. خطاهای شبکه/۵xx حداکثر سه تلاش با backoff دارند. CAPTCHA و ۴۰۱/۴۰۳/۴۲۹/۴۵۱/۴۹۰ بدون تلاش خودکار مجدد متوقف می‌کنند؛ Retry-After در SQLite ذخیره و هنگام Resume رعایت می‌شود. تغییر schema یا ترتیب، توقف قابل‌بازیابی ایجاد می‌کند؛ فقط با اصلاح adapter بر اساس مشاهدهٔ جدید ادامه دهید.

برای بررسی دستی پس از محدودیت، بات را با `Ctrl+C` ببندید و اجرا کنید:

```bash
python -m torob_bot --review
```

همان پروفایل Chromium باز می‌شود؛ خودتان به سایت بروید و وضعیت را بررسی کنید. این حالت اسکرپ نمی‌کند و CAPTCHA را خودکار حل نمی‌کند. پنجره را ببندید، بات را اجرا کنید و فقط پس از رفع محدودیت `/resume` بزنید. پروکسی چرخشی، stealth، سرویس حل CAPTCHA یا دورزدن محدودیت پیاده‌سازی نشده است.

`Ctrl+C` و SIGTERM وضعیت را نگه می‌دارند. پس از crash، عملیات running به interrupted تبدیل می‌شود؛ ادامه خودکار نیست. خواب مک، بسته‌شدن پنجره و قطع شبکه می‌توانند عملیات را مختل کنند. از پروفایل اختصاصی برنامه برای ورود به حساب‌های حساس استفاده نکنید.

## فایل‌ها و آزمون

`torob_bot/config.py`: تنظیمات؛ `storage.py`: SQLite و خروجی؛ `scraper.py`: مرورگر/adapter؛ `bot.py`: مجوزها و worker؛ `__main__.py`: CLI و قفل فرایند. لاگ خام HTTP و استثناهای SDK منتشر نمی‌شوند؛ پیام‌ها فقط کد خطا دارند.

داده‌ها در `data/torob.sqlite3`، پروفایل در `data/browser-profile/` و خروجی در `data/exports/` هستند. برای پشتیبان‌گیری، اول برنامه را ببندید و کل data را کپی کنید. `.env` و data خصوصی و خارج Git هستند.

```bash
python -m unittest -v test_core
# تست واقعی محلی، فقط با مجازبودن دسترسی؛ بدون نیاز به تلگرام:
python -m torob_bot --query "تشک" --limit 10
# ادامهٔ عملیات CLI شمارهٔ ۱:
python -m torob_bot --resume 1
```

CLI کد خروج صفر را فقط برای تکمیل همهٔ N محصول می‌دهد؛ محدودیت/نقص کد ۲ دارد. `--headless` صرفاً برای عیب‌یابی CLI است؛ بات تلگرام همیشه Headed است. عملیات CLI مالک داخلی ۰ دارد و از تلگرام قابل‌کنترل نیست. برای آزمایش مستقل از دادهٔ بات، DATA_DIR جدا تعیین کنید.
